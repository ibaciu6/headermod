HeaderMod

A Chrome and Firefox extension that modifies HTTP request and response headers per profile — a clean Manifest V3 rebuild built on declarativeNetRequest.

GitHub

Features

  • Multiple named profiles of request/response header rules
  • Per-rule enable/disable
  • URL filters (regex) and resource-type filters
  • Tab lock — apply a profile only to the active tab
  • Pause / resume all rules without deleting them
  • Cloud backup — timestamped profile snapshots via browser sync
  • Import / export profiles as JSON

Privacy

HeaderMod transmits no data to the developer or any third party. See the full Privacy Policy.
